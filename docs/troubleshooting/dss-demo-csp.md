# European Commission DSS demo: localhost CSP compatibility

The European Commission DSS demonstration allows its browser page to connect to `https://localhost:9895` through its Content-Security-Policy. The equivalent numeric loopback URL `https://127.0.0.1:9895` is not allowed by that policy and is blocked by the browser before the request reaches NexU.

NexU therefore keeps the secure server bound to the numeric loopback interface while advertising `localhost` in `/nexu.js` and `/nexu-v2.js`:

```properties
binding_ip=127.0.0.1
binding_ports_https=9895
nexu_hostname=localhost
```

Numeric loopback values in older external configuration files are normalized to `localhost` when browser scripts are rendered.

For an older release, edit the external `nexu-config.properties` file, set `nexu_hostname=localhost`, restart NexU and hard-refresh the DSS signing page. Verify that the browser calls:

```text
https://localhost:9895/rest/certificates
```

and not:

```text
https://127.0.0.1:9895/rest/certificates
```

A `GET /server-sign` 404 generated by the DSS demonstration is an upstream availability/fallback request. It is separate from the NexU certificate call; the blocking error to fix is the browser CSP rejection of the numeric loopback URL.
